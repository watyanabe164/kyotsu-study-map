# 学習管理ツール（作問はAIによろしく）

子どもの共通テスト対策用に作った、ブラウザだけで動く学習管理ツールです。
Claudeを活用して開発しました。

## 特徴

- **実行環境ゼロ**：HTMLファイルをダブルクリックするだけで動く
- **問題データを外部AI任せ**：アプリ本体は問題を持たず、プロンプトを出力してAIに生成させる設計
- **JSONをマージするだけで単元追加**：GeminiやClaudeが出力したJSONを貼り付けるだけ
- **進捗をLocalStorageに保存**：サーバ・アカウント不要

## 使い方

### 1. ダウンロードして開く

`index.html` をダウンロードしてブラウザで開くだけです。

### 2. 問題を追加する

アプリ下部の **「AIアドオン・データ管理システム」** パネルを使います。

1. 「📋 Gemini用プロンプトをコピー」ボタンを押す
2. コピーされたプロンプトをGemini / Claude / ChatGPTに貼り付け、追加したい科目・単元を指定する
3. AIが出力したJSONをテキストエリアに貼り付ける
4. 「⚡ アドオンを適用する」を押す

攻略マップに新しい単元が即時反映されます。

### 3. 演習する

マップ上の単元カードをクリックすると4択クイズが始まります。80%以上でEXPを獲得、レベルアップします。

## 問題データのフォーマット（JSON）

AIに生成させるデータの構造です。カスタムデータを直接作ることもできます。

```json
[
  {
    "subj": "科目名",
    "sid": "一意のID（英数字）",
    "icon": "絵文字",
    "units": [
      {
        "id": "sid-連番",
        "name": "単元名",
        "qs": [
          {
            "q": "問題文（\\nで改行）",
            "h": "視点のヒント",
            "cs": ["選択肢0", "選択肢1", "選択肢2", "選択肢3"],
            "a": 0,
            "e": "解説文"
          }
        ]
      }
    ]
  }
]
```

- `a` は正解のインデックス（0始まり）
- 同じ `sid` の科目・同じ `id` の単元は自動でマージされ、問題の重複は排除されます

## 設計思想

「問題生成AIの入出力インターフェースを作る」という考え方でツールを設計しました。

```
アプリ → プロンプト生成（現在の単元構造を動的に埋め込み）
     → AIが構造を理解した上でJSONを生成
     → アプリにマージ → 単元が増える
```

ツール本体のコードを最小限に保ちつつ、AIの能力で問題を無限に拡張できます。

## カスタマイズ

共通テストに限らず、JSONの科目・単元を変えれば：

- 資格試験対策
- 中学受験
- 社内研修の確認テスト

など、様々な用途に転用できます。
